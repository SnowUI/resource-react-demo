# SnowUI Resource React Demo

Interactive Vite + React gallery and integration demo for `@snowui-design-system/resource-react` (icons, avatars, backgrounds, illustrations, logos, and `IconProvider` switching).

- Resource package: https://github.com/SnowUI/resource-react (`@snowui-design-system/resource-react`)
- Base asset package: https://github.com/SnowUI/resource-base (`@snowui-design-system/resource-base`)
- SnowUI website: https://snowui.dev · [AGENTS.md](./AGENTS.md)

## Run Locally

```sh
pnpm install
pnpm dev
```

Build static preview:

```sh
pnpm build
pnpm preview
```
